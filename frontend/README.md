# Vulnity Web Interface

React and TypeScript frontend for the Vulnity API.

## Requirements

- Node.js
- npm

## Run locally

From this directory:

    npm install
    npm run dev

Vite prints the local URL in the terminal. The interface expects the API to be available at the address configured in its API client. For backend setup and CORS settings, see the [root README](../README.md).

## Checks

    npm run lint
    npm run build

## Scripts

- dev — start the Vite development server
- lint — run ESLint
- build — type-check and create the production build
- preview — serve a local production build
